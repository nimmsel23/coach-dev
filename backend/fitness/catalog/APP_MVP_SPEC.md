# Vitaltrainer App MVP Spec

## MVP Demo

Der erste App-MVP zeigt einen vollständigen Lern- und Trainingsfluss:

1. Dashboard oeffnen
2. Push Day anzeigen
3. Uebung `dips_chest` oeffnen
4. Muscle Coverage und Body Regions sehen
5. Anatomy Meaning lesen
6. Coaching Cues sehen
7. Coach Sheet nach Obsidian exportieren

## MVP Screens

### 1. Dashboard

Zeigt:

- heutiger Trainingsvorschlag
- letzter Plan
- offener Lernfokus
- Coverage-Hinweis
- Schnellaktionen

### 2. Plan View

Zeigt:

- Push/Pull/Legs Plan
- Uebungen
- Saetze
- Wiederholungen
- RPE
- Pausen
- Begruendung pro Uebung
- Coverage Summary

### 3. Exercise Detail View

Zeigt:

- Name
- deutscher Name
- Kategorie
- Equipment
- Bewegungsmuster
- primaere Muskeln
- sekundaere Muskeln
- Stabilisatoren
- Body Regions
- Coaching Notes
- Common Errors

### 4. Exercise Meaning View

Zeigt:

- Was lehrt diese Uebung?
- Welche Gelenke arbeiten?
- Welche Muskeln erzeugen Kraft?
- Welche Muskeln stabilisieren?
- Was soll man spuen?
- Welche Fehler passieren?
- Warum passieren sie?
- Wie coacht man sie?

### 5. Coverage View

Zeigt:

- Muscle Coverage
- Body Highlighter Regions
- Intensitaetsstufen
- optional: Anatomy Coverage

### 6. Export View

Zeigt:

- Obsidian Preview
- Export Button
- Zielpfad
- Warnung vor Ueberschreiben

## MVP Scope

Nicht noetig im ersten App-MVP:

- Login
- Cloud
- Multi-User
- Mobile App
- vollstaendiger wger Sync
- komplette Uebungsdatenbank
- komplexes UI
- KI-Generierung

## MVP Outcome

Ein Nutzer oeffnet die App, sieht einen Push Day, oeffnet Dips, versteht die Uebung, sieht Coverage und exportiert eine Notiz nach Obsidian.
