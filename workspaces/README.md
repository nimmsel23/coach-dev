# C-Suite workspaces (Git-Brain)

Rollen-Gehirne für das Coach+Klienten Delivery-Cockpit. State (Chats, Freigaben)
lebt in Firestore `csuite/{role}/…`, nicht hier.

| Ordner | Rolle | UI |
|--------|-------|----|
| `coo/` | Coaching-Delivery & Kundenerfolg | `/coo.html` |

Weitere Rollen (cmo, cfo, …) folgen demselben Schema: `config.json`,
`system-prompt.md`, `skills.json`, `knowledge/`.
